# 实验报告处理脚本使用说明

## 📋 概述

本文件夹包含用于处理实验报告的Python脚本，可以读取、修改和生成Word文档。

## 📁 文件列表

| 文件 | 说明 |
|------|------|
| `report_processor.py` | 主脚本 - 读取、修改、生成报告 |
| `report_generator.py` | 辅助脚本 - 生成完整报告 |
| `README.md` | 使用说明 |

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install python-docx
```

### 2. 运行脚本

```bash
cd 实验报告
python report_processor.py
```

### 3. 功能菜单

```
============================================
      实验报告处理脚本
============================================
1. 读取现有文档
2. 修改现有文档
3. 创建新报告
4. 退出
============================================
请输入选择 (1/2/3/4):
```

## 📖 功能说明

### 功能1：读取现有文档

读取并显示Word文档内容，帮助了解当前报告内容。

```
请输入文档路径: 计科实践报告 (2).docx
✅ 成功读取文档: 计科实践报告 (2).docx
📄 段落数: 45
📊 表格数: 2

文档内容预览
============================================
  1. 2025-2026-2
  2. 信息系统设计与实践 & 软件工程实践
  3. 报告书
...
```

### 功能2：修改现有文档

根据项目内容自动更新指定章节：

- **实验任务** - 更新模块列表和预期效果
- **技术路线** - 更新技术栈和架构图
- **系统实现** - 更新API接口列表
- **功能测试** - 更新测试用例

### 功能3：创建新报告

自动生成完整的实验报告，包含：

1. 封面（班级、学号、姓名等）
2. 报告书写要求
3. 实验任务（项目概述、模块列表）
4. 技术路线（架构图、技术栈）
5. 系统实现（界面设计、数据库设计、API接口）
6. 系统部署（本地开发、Linux部署）
7. 功能测试（测试用例）
8. 总结

## ⚠️ 注意事项

1. 确保安装了Python 3.6+
2. 确保安装了python-docx库
3. 文档路径请使用完整路径或相对路径
4. 修改文档前建议备份原文件
5. 脚本会自动保存修改，请注意确认
